# Create a distinctive production-grade frontend interface

## When
Use when creating a frontend interface that needs a clear conceptual direction, high design quality, accessibility, and precise implementation rather than cookie-cutter aesthetics.

## Material
The interface purpose, users, tone, framework, performance and accessibility constraints, and the features that make the design distinctive and context appropriate.

## Done
A production-grade frontend with intentional typography, cohesive theme variables, deliberate motion and spatial composition, and implementation complexity matched to the chosen aesthetic direction.

## Requires
A frontend implementation environment and an explicit aesthetic direction covering purpose, tone, constraints, and differentiation before coding.

## Replaces
Overused fonts, cliched color schemes, predictable layouts, and cookie-cutter designs without context-specific character.

## Not for
Backend API reviews, database schema reviews, infrastructure or DevOps work, pure business logic without UI, or other non-frontend code. For review of an existing UI, use the `microsoft/skills/frontend-design-review--ui-review` card.
