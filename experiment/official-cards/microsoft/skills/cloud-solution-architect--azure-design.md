# Design or review an Azure cloud architecture

## When
Use when designing cloud systems, reviewing system designs, selecting architecture styles, applying cloud design patterns, choosing Azure technologies, or conducting a Well-Architected Framework review.

## Material
Functional requirements and non-functional requirements for availability, latency, throughput, data residency, compliance, recovery, and cost, plus an existing design when performing a review.

## Done
An architecture style and technology selection supported by relevant design patterns, explicit Well-Architected Framework tradeoffs, cross-cutting concerns, and Architecture Decision Records documenting decisions and consequences.

## Requires
The bundled Azure Architecture Center references for design patterns, technology choices, best practices, and mission-critical design. The documented workflow itself does not require live service access.
