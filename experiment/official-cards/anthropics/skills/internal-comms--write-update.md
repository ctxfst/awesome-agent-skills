# Write an internal communication in the documented company format

## When
Use for 3P updates, company newsletters, FAQ responses, status reports, leadership updates, project updates, incident reports, and other internal communications.

## Material
A request identifying the communication type and the context needed to gather its content. If no existing guideline matches the requested type, the instructions require asking for clarification or more format context.

## Done
An internal communication that follows the corresponding guideline from the bundled examples directory for formatting, tone, and content gathering.

## Requires
The appropriate bundled guideline file: 3p-updates, company-newsletter, faq-answers, or general-comms for other cases.
